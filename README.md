# Desafio Task Manager

Aplicação web desenvolvida para o desafio técnico do Programa Protagonize Tech utilizando Angular no front-end e ASP.NET Core Web API no back-end.

## Tecnologias Utilizadas

### Front-end
- Angular
- TypeScript
- HttpClient

### Back-end
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server

## Funcionalidades
- Listagem de tarefas
- Cadastro de tarefas
- Edição de tarefas
- Exclusão de tarefas

## Estrutura do Projeto

/backend
- API ASP.NET Core

/frontend
- Aplicação Angular

## Como Executar o Projeto

### Backend

Acesse a pasta:

cd backend/TaskApi

Execute os comandos:

dotnet restore
dotnet run

A API será iniciada em:

http://localhost:5055

### Frontend

Acesse a pasta:

cd frontend/task-app

Execute os comandos:

npm install
ng serve

O Angular será iniciado em:

http://localhost:4200
